# Currency system

`CurrencyManager` displays the signed-in player's coin and gem balance and owns currency reward rules.

- New and existing profiles receive the one-time starting balance of 300 coins and 100 gems.
- Each online skate-mode kill awards 10 coins to the player who earned it.
- Balances use the existing cloud-backed profile queue, so rewards remain visible immediately and retry safely when saving.
- Gems have no earn or spend action yet. Purchases and rewarded ads will be added later.
